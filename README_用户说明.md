# PMSM 性能分析工具 v0.4.1

## 启动

解压发布 ZIP，进入 `PMSM_Performance_Tool_v0.4.1`，双击
`PMSMPerformanceTool.exe`。请保留 `_internal` 目录与程序在同一目录。

## 输入方式

- `Udc + Tmax + nmax`：按 Tmax 的 MTPA 点反算等效 `Is_max`。
- `Udc + Is_max + nmax`：直接采用输入的定子电流矢量峰值限制。

两种模式都统一转换为 dq 电压矢量峰值 `Umax`、定子电流矢量峰值
`Is_max` 和最高转速 `nmax`。SVPWM 默认采用
`Umax = 电压利用率 × Udc / sqrt(3)`。

## 使用流程

1. 选择输入方式并填写电机参数、Udc、转速和转矩或电流。
2. 在高级设置中按需配置 Id、功率、网格和损耗模型。
3. 点击“开始计算”；参数变化只会把旧结果标记为过期，不会自动计算。
4. 在外特性图、效率 Map、dq 图或数据表中点击工作点查看联动信息。
5. 使用导出按钮生成 CSV、NPZ、Excel 或 PNG。

## 电感模型与绕组接法

- 固定电感：使用界面输入的 Ld/Lq。
- 饱和 Map：Excel 必须包含 `Ld`、`Lq` 工作表；A1 为说明，第一行为 Iq[A]，第一列为 Id[A]，默认电感单位 μH。范围外工作点无效，不进行外推。
- 星接、角接按逆变器线电流/电压与物理绕组量进行换算。
- 开绕组支持双逆变器共母线、隔离母线及自定义两侧 Udc；Udc 是每侧逆变器母线电压。

## 案例对比

“案例管理”可保存当前正式计算、加载或删除案例，并多选叠加外特性与 dq 轨迹。案例对比页可查看单独 Efficiency Map，以及 A-B 的效率百分点差和转矩差。案例保存在程序旁的 `cases` 目录。

效率 Map 默认显示效率百分比，蓝色为低值、红色为高值；可从“显示选项”
切换铜耗、铁耗、总损耗、Id、Iq 和可选等值线。包络外区域留白。

## 单位约定

计算层统一使用 SI 单位、相电流峰值和 dq 电压矢量峰值。若界面选择 RMS，
程序会先转换为峰值。铁耗结果仅在模型系数经过标定时具有工程意义。
